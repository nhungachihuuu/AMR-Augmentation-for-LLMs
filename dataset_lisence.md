# Dataset Licenses

This file documents the license and source information for all datasets redistributed in this repository for research reproducibility purposes. Please review each license before using the data.

> **Note on data modification:** In our redistributed version, each sample is augmented with its corresponding AMR, parsed using AMR3-structbart-L. Additionally, we use a sampled subset of the original data rather than the full corpus; please refer to the paper for details on subset sizes and sampling procedures. If you use any of these datasets in your own work, please cite the original sources and comply with the respective license terms.
